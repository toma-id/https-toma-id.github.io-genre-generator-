# TOMA ID — SCREENPLAY GENRE GENERATOR

A niche screenplay genre generator for screenwriter [Toma](https://toma-id.github.io/).

Pick a **Territory**, a **Form**, and a **World** — get a unique niche genre combination. Then order a screenplay.

## How it works

- The hero cycles through niche genre phrases with a Frank LeBon–style irregular rhythm — re-randomised on every page load
- Three sequential selectors unlock one by one
- When all three are chosen, your genre appears and the **ORDER SCREENPLAY** button activates

## Deploy on GitHub Pages

1. Go to your repo → **Settings → Pages**
2. Source: `main` branch, folder: `/ (root)`
3. Save — your site will be live at `https://your-username.github.io/your-repo/`
